# Key Mouse Counter

一个轻量级的键盘鼠标按键计数器，后台运行于系统托盘，记录每个按键的按下次数与按住时长，支持每日统计、总计以及热力图可视化。

## 功能

- **实时计数**：全局监听键盘与鼠标事件，记录按键次数、按住时长，以及鼠标移动距离。
- **每日/总计统计**：数据按天保存，自动跨天，保留历史。可设置保留天数。
- **统计界面**：可视化键盘热力图，支持切换次数/时长模式，查看任意日期或总计数据。
- **鼠标移动距离**：根据设置中的屏幕物理尺寸，将像素移动转换为米。
- **开机自启**：通过系统托盘菜单一键开关。
- **轻量后台**：仅托盘图标，无主窗口，资源占用极低。

## 项目结构
Key Mouse Counter/
├── main.py # 入口，协调各模块，处理托盘消息与窗口创建
├── counter.py # 核心计数器，线程安全地管理按键状态、每日/总计统计
├── listener.py # 键盘鼠标事件监听（基于 pynput），支持调试日志
├── data_manager.py # 数据持久化，读写 JSON 文件，清理过期数据
├── tray_app.py # 系统托盘图标与菜单
├── settings_window.py # 设置界面（保留天数、屏幕尺寸、热力图颜色等）
├── stats_window.py # 统计界面（键盘热力图、汇总信息、日期切换）
├── keyboard_layout.py # 键盘布局定义（物理位置、键码映射）
└── requirements.txt # Python 依赖

## 数据存储

- 所有数据保存在程序同级的 `data/` 文件夹。
- **每日统计**：`YYYY-MM-DD.json`，记录当天每个键的次数、时长，以及鼠标移动距离。
- **总计统计**：`total.json`，跨天的累加数据。
- **设置文件**：`settings.json`，保存保留天数、屏幕尺寸、热力图颜色等。
